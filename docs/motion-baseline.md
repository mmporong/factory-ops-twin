# 운영 주행과 물리 기준선

## 현재 연결

운영 모드는 `PathMotion`이 작성한 경로의 이동시간·회전·가감속을 계산한다. 물리 기준선은 Isaac Sim 4.5의 Nova Carter 바퀴와 차체를 실행한 보존 결과다. 적재 시험135와 엔코더 경로 추종 시험226은 범위가 다르다. 세 모드는 바퀴 기하와 제한값의 의미를 공유하지만, 운영 궤적을 물리 실측이나 경로 추종 정확도로 표시하지 않는다.

| 항목 | 운영 모드 | 적재 물리 시험135 | 경로 추종 물리 시험226 |
|---|---|---|---|
| 차량 |4대의 원형 외곽과 차동 구동 기구학 | Nova Carter 한 대·차체 고정 운반대·자유 동역학6kg 토트 | 무적재 Nova Carter 한 대 |
| 제어 | 경유점별 quintic 정지→회전→이동→정지 | 시간별 속도 명령→DriveProfile→바퀴 목표속도 | 엔코더 odometry→pure pursuit→DriveProfile→바퀴 목표속도 |
| 경로 | 작성된 공장 그래프 | 짧은 전진·곡선·제자리 회전 명령 |2m 직선→반경2m quarter arc→종점 정지·yaw 정렬 |
| 바퀴 반경 / 간격 |0.14m /0.4132m | 에셋 충돌 형상에서 약0.1400000006m /0.4131999877m |0.14m /0.4132m 작성값 |
| 선속도 / 각속도 상한 |0.6m/s /1.2rad/s |0.2m/s /0.4rad/s |0.6m/s /1.2rad/s. cruise 명령은0.59m/s |
| 선가속 / 감속 |0.25m/s² /0.35m/s² |0.1m/s² /0.15m/s² |0.25m/s² /0.35m/s² |
| 각가속 / 감속 |0.5rad/s² /0.7rad/s² |0.25rad/s² /0.4rad/s² |0.5rad/s² /0.7rad/s² |
| 위치 원천 | 모델 계산 좌표 | 엔코더 적분·PhysX 차체 관측. GT는 평가에만 사용 | 엔코더 적분만 제어·goal 수락에 사용. GT는 독립 평가에만 사용 |
| 적재물 | 원장 상태와 가상 에너지 소모에 반영 | 접촉·동역학을 가진 토트의 제한된 주행 시험 | 없음.135의 접촉 물리 결과를 결합해 주장하지 않음 |
| 한계 | 접촉·마찰·위치추정·센서 지연·추종 오차 없음 | 공장 경로·Nav2·자동 적재/도킹·산업용 적재 정격 미검증 | 공장 경로·Nav2·fleet·회피·도킹·운송 미검증 |

수치는 [운영 설정](../configs/factory-semiconductor-dual-lane/g2.json)과 [물리 시험135 원본 요약](evidence/local45-loaded-mobility-135.json)의 `native_result.loaded_motion_config`, `drive_geometry`에서 읽었다. 에셋 형상과 수치가 맞는다는 사실은 실제 모터·타이어·배터리 보정을 뜻하지 않는다. 더 낮은 물리 시험 속도에서 통과한 결과를0.6m/s 공장 운행의 검증으로 확대하지 않는다.

## 재사용하는 실제 결과

- [124](evidence/local45-loaded-carrier-124.json): 운반대의 정적 장착과 형상 확인. 적재 주행 결과로 세지 않는다.
- [128](evidence/local45-loaded-mobility-128.json):6kg 적재 상태의 전진·곡선·제동·제자리 회전.20fps 촬영 설정.
- [135](evidence/local45-loaded-mobility-135.json): 같은 이동 조건의60fps 촬영. 전진 차체 변위 약0.22447m, 곡선 yaw 변화 약0.23109rad, 제자리 회전 yaw 변화 약0.30651rad를 기록했다. 이 값은 각 짧은 명령 구간의 결과이며 산업용 주행 정확도 규격이 아니다.
- [142](evidence/local45-junction-hero-142.json): 네 차량의 교차 통로 양보·통과·재개. 동적 전역 우회나 ROS/Nav2 전체 물류 완주로 세지 않는다.
- [226 결과와 궤적](evidence/local45-path-baseline-226.json) · [그래프](evidence/local45-path-baseline-226.svg):843개·14.033334초 표본에서 엔코더 goal을 위치 오차0.032512m·yaw 오차0.047695rad로 수락했다. 독립 GT 평가는 횡오차 RMS0.047592m·최대0.076484m, 종점 오차0.071221m, 정지 후 이동0.000010m를 기록했다. 실제 최대 전진 속도0.591455m/s로0.6m/s 한계를 통과했다.
- [231 도킹 정렬 결과](evidence/local45-docking-alignment-231.json) · [그래프](evidence/local45-docking-alignment-231.svg): 무적재 Nova Carter가 엔코더 odometry만으로 저속 접근·yaw 정렬·1초 정지 확인을 마쳤다. 엔코더 수락 오차는 위치0.004547m·yaw0.033796rad였고, 독립 GT 평가는 종점0.004187m·yaw0.034983rad·정지 후 이동0.000577m를 기록해6개 검사를 통과했다.

124/128/135와226/231은 SDK 종료와 소유 프로세스0개를 확인한 결과다.226과231의 실행 전5개 입력은 영수증 해시와 대조한 뒤 각 실행 폴더의 `frozen-source`에 보존했다. 해당 에셋은 SDK native resolver의 URL로 해석됐으며, 이 기록에 없는 로컬 에셋 파일 해시를 새로 추정해 채우지 않는다. 현재 공장의 제공처 에셋 색인과 이 차량 시험의 자산 근거를 구분한다.

## 단일 차량 도킹 정렬 물리 시험231

[도킹 설정](../configs/local45-docking-alignment.json)과 [SDK 실행 도구](../scripts/isaac/probe_docking_alignment.py)로 Isaac Sim 4.5 시험을 실행했다. 무적재 차량은 엔코더 기준 `(1.48m, 0.08m, 0.18rad)` 목표로 저속 접근하고 방향을 맞춘 뒤1초간 정지했다. 요청 순항 속도는0.14m/s, 상한은0.15m/s·0.4rad/s이며 기존 `DriveProfile`의 가감속 제한을 사용했다. 제어·정지 수락에는 엔코더 odometry만 넣고 시뮬레이터 GT는 종료 후 평가했다.

| 판정 | 엔코더 제어 수락 | 독립 GT 평가 |
|---|---:|---:|
| 위치 오차 |0.025m 이하 |0.06m 이하 |
| yaw 오차 |0.035rad 이하 |0.08rad 이하 |
| 정지 확인 |선속도0.01m/s·각속도0.015rad/s 이하를1초 유지 |수락 이후1초간 위치 이동0.01m 이하 |
| 실행 상한 |45초 시뮬레이션 |600초 벽시계·RGB180장 이하 |

1002개 표본의 제어 구간은16.683334초였다. 독립 GT의 실제 최대 전진 속도는0.140938m/s, 최대 각속도는0.041603rad/s였다. 4fps 실제 RGB66장을 기록했으며 보간이나 중복 프레임을 만들지 않았다. 실행 전5개 입력의 해시를 확인하고 동결했으며, Windows Job 종료 뒤 소유 PID는0개였다.

비정렬 시작의 수렴, 속도·가감속 한도, 정지 확인 도중 이동 시 dwell 초기화, 엔코더 수락과 별개인 GT 실패 사례도 CPU에서 확인했다. 시각 패드는 작성 목표 pose를 표시하는 표식이다. 이 시험은 물리 접촉 센서, 전기 접점, 충전 전력, 자동 하역을 확인하지 않는다. `physical_contact_verified`, `electrical_contact_verified`, `virtual_charging_applied`는 false다.

운영 모델에서 교통 정책의 물류 결과를 먼저 비교한다.226은 무적재 단일 차량의 직선·연속 곡선 추종과 종점 정지를 확인했다. 적재 상태의 같은0.6m/s 범위, 공장 경로의 장애물·센서·관측 지연, 여러 차량의 회피와 도킹은 별도 시험이 필요하다. 기존 전체 운송 실패074를 같은 조건으로 반복해 이 지표를 대신하지 않는다.

강화학습 확장은 전역 배차와 예약을 유지한 채 로컬 주행 제어기를 교체하는 별도 비교로 다룬다. 기존 Nav2 기준선과 같은 센서 입력·작용 범위·평가 장면을 사용해야 한다. 학습 정책이나 RL 우월성은 현재 산출물에 포함하지 않는다. 공식 자료와 직무 연결은 [완성 계약의 주행 제어 절](completion-plan.md#주행-제어강화학습-확장-후보)에 정리했다.
